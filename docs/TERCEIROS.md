# Bibliotecas de interface

Arquivos locais em `static/vendor`, obtidos das distribuições públicas do jsDelivr. Os avisos de licença nos arquivos foram preservados; comentários de source map foram removidos quando aplicável.

| Biblioteca | Versão | Licença | Projeto |
|---|---|---|---|
| Bootstrap | 5.3.8 | MIT | https://github.com/twbs/bootstrap |
| Chart.js | 4.5.1 | MIT | https://github.com/chartjs/Chart.js |
| FullCalendar (standard, locale e Luxon plugin) | 6.1.20 | MIT | https://github.com/fullcalendar/fullcalendar |
| Luxon | 3.7.2 | MIT | https://github.com/moment/luxon |
| Lucide | 0.468.0 | ISC | https://github.com/lucide-icons/lucide |

Dependências Python são instaladas pelo pip a partir de requirements.txt e mantêm suas próprias licenças. Esta distribuição não inclui componentes premium do FullCalendar.
